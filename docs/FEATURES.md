- **33 service workflows:** complete local simulations with individual fields/evidence/review role/outcomes.
- **10 role portals:** actual server sessions and API restrictions.
- **460 registry entries:** preserved requirements, not 460 completed production capabilities.

Government APIs, real payment collection, OTP/NID, official digital signatures, true cadastral geometry, live field sync, AI/OCR and legal inheritance decisions are **not implemented**.
