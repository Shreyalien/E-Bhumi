# Feature status — version 4

- **33 service workflows:** complete local simulations with individual fields/evidence/review role/outcomes.
- **15 role portals:** actual server sessions and API restrictions.
- **460 registry entries:** preserved requirements, not 460 completed production capabilities.

Implemented: registration/login/logout, profile/password change, role account management, intake settings, draft edits, evidence upload/download/hashing, submit/withdraw, staff claim, correction/resubmission, hearing, reasoned decision, sandbox fee failure/retry/replay protection, finance reconciliation, outcome issuance/download, notifications, reports, audit export/chain check, sample map/passport, calculators and guided discovery.

Government APIs, real payment collection, OTP/NID, official digital signatures, true cadastral geometry, live field sync, AI/OCR and legal inheritance decisions are **not implemented**.
